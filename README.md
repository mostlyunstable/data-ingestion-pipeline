# ⚡ OmniLead Autopilot
### Autonomous Client Ingestion Pipeline for Technical Freelancers

OmniLead Autopilot is a **zero-manual-input data ingestion engine** built specifically for freelancers offering:
1. **Chatbots** (AI Support, Lead Qualification, Conversational AI)
2. **Web Development** (Modern React/Next.js, UI/UX Revamps, Speed Optimization)
3. **App Development** (Mobile iOS/Android Native & Flutter/React Native)
4. **Automation** (n8n, Zapier, Webhooks, CRM Syncing)
5. **Custom Data Pipelines** (ETL, Scraping, API Syncing, Backend Engineering)

You do **not** need to upload CSV files, create campaigns, or type search queries and locations.

---

## 🤖 How the Autonomous Engine Works

```
  [ AUTOPILOT SOURCES ]
   • Newly Launched Startups (Product Hunt / HN / Incubator Feeds)
   • Active Engineering & Dev Hiring Signals
   • Pre-mapped High-Intent Business Corridors (US, UK, India, Canada)
                           │
                           ▼
              [ DEEP TECHNICAL AUDIT ]
   • 🤖 Chatbot Check: Missing 24/7 AI chatbot or live support?
     ➔ Flagged: "Needs Chatbot"
   • 📱 Mobile App Check: Growing platform with no iOS/Android apps?
     ➔ Flagged: "Needs App Dev"
   • 🌐 Web Stack Audit: Outdated CMS, legacy jQuery, poor speed?
     ➔ Flagged: "Needs Modern Web Dev"
   • ⚡ Pipeline & Automation Audit: Form bottlenecks, catalog syncs?
     ➔ Flagged: "Needs Automation & Custom Pipelines"
                           │
                           ▼
          [ HARVEST DECISION MAKERS & INBOXES ]
   • Direct, verified company emails (filtering template junk)
   • Direct phone numbers (India +91 & International +1, +44)
   • Founders & Leadership LinkedIn links
                           │
                           ▼
           [ TAILORED PROPOSITION GENERATOR ]
   • Drafts a custom pitch hook specifically attacking that exact technical flaw.
   • Automatically stores and deduplicates into your local SQLite database.
```

## 🚀 How to Run It (1-Click)

Run in your terminal:

```bash
cd "/Users/caffinelove/Data ingestion pipeline"
python3 run.py
```

Your browser will automatically open to:
👉 **`http://localhost:8000`**

- The **24/7 Autopilot Daemon** is active automatically in the background.
- Whenever you open your dashboard, you will see a fresh stream of businesses, their technical flaws, verified inboxes, and ready-to-send pitches.
- Click **"Ingest 15 Fresh Leads Now"** at any time to run an instant autonomous sweep.
- Filter by technical need: `[Needs Chatbots]`, `[Needs Web Dev]`, `[Needs App Dev]`, or `[Needs Automation]`.
- Click **"Export Clean Leads (CSV)"** to take all captured leads into Excel or Google Sheets.
